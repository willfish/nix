Lesson 0001 Phase 2 to Phase 3 Artifact: AI system one-pager

What Makes an AI Feature a System?

A Phase 2 engineer can make a model useful. A Phase 3 engineer can make the model part of an operated system: constrained, measured, interruptible, observable, and replaceable.

The Win

By the end of this lesson, you will have a one-page design for an AI system that sounds like production engineering rather than AI feature enthusiasm. This becomes the seed of your first portfolio case study.

The Shift

Traditional backend foundation

You already know APIs, databases, queues, caching, auth, cloud, security, and observability. Keep that identity. It is the base layer.

Bridge-layer AI features

LLM APIs, embeddings, vector databases, RAG, context engineering, tool calling, and routing make AI useful inside applications.

AI systems engineering

Agents, state, memory, MCP boundaries, evals, guardrails, human review, traces, cost controls, and fallbacks make AI reliable enough to own.

Source Material

Use these as the primary reading queue for this lesson. The companion reference is source-map.html.

  • OpenAI Function calling: tool contracts and application-owned actions.
  • OpenAI Evals: datasets, testing criteria, graders, and regression checks.

  • OpenTelemetry GenAI conventions: traces, metrics, events, exceptions, agent spans, and MCP observability vocabulary.

The Production Lens

Goal

What user or business outcome is the system accountable for?

Tools

What can the model request, and what does application code execute?

State

What does the workflow remember during a run and across runs?

Evals

What examples prove expected behavior and catch regressions?

Guardrails

What inputs, outputs, actions, or data access need constraints?

Human review

Where should the system pause before risk crosses a boundary?

Observability

What traces, metrics, logs, and costs must be visible?

Fallbacks

What happens when the model, tool, retrieval, or budget fails?

Quick Check

Which description best signals AI systems engineering rather than bridge-layer feature work?

Choose an answer, then check it.

Exercise: Draft Your First AI System One-Pager

Pick a small but real workflow. Good options: PR review assistant, Jira triage assistant, release-note generator with human approval, incident summarizer, or personal knowledge assistant with MCP access.

Fill in the draft, then score it. A credible Phase 3 one-pager covers at least seven production concerns.

Marketing Translation

Weak positioning: Backend engineer learning AI

Stronger positioning: Backend engineer specializing in production AI systems: agents, tool orchestration, evals, observability, guardrails, and reliable integration with existing software systems.

Your proof should be a case study, not a claim: architecture, tradeoffs, eval suite, traces, cost profile, failure modes, and a demo path.
