# Terminal Demos

Use this when a CLI change needs a visual demo.

Selection:
- Use asciinema plus agg for simple command output.
- Use gpu-screen-recorder plus ffmpeg for tmux, vim, htop, or other TUI/full-screen demos.

Read `references/terminal-demos.md` for driver scripts, recording commands, and conversion steps.
