# Skill loading

Discover task-relevant installed skills using `skill_catalog`, then read the
selected skill before acting. Load `systematic-debugging` for failures and
`verification-before-completion` before completion claims, commits or pushes.
Use the applicable domain workflow for authentication, accounting, browser
control, dependency changes and publication. Private workflows are supplied by
the local overlay and are not assumed to exist in every installation.

Honour explicit skill requests and manual-only invocation metadata. Discovery
never authorizes actions. Preserve secret protections and human approval gates.
For skill or guide prose, read `~/.agents/guides/documentation-relevance.md`.
